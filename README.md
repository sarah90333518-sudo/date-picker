# 🌲 모여봐요 약속의 숲 (Streamlit 버전)

파이썬의 **Streamlit** 프레임워크로 제작된 약속 날짜 투표 및 최적 날짜 자동 추천 애플리케이션입니다.

## 🚀 로컬에서 실행하기

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🌐 Streamlit Community Cloud (무료 호스팅)

1. 이 저장소를 GitHub에 올립니다.
2. [share.streamlit.io](https://share.streamlit.io) 접속 ➔ GitHub 로그인
3. **[New app]** ➔ 저장소 선택 (`app.py` 지정) ➔ **[Deploy!]**
4. 무료 공유 주소 발급 완료!
